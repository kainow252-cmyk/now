**É como ter um assistente executivo, trader, personal shopper e analista financeiro em uma única IA.**

## ⚡ INÍCIO RÁPIDO (5 minutos)

```bash
# 1. Clone o projeto
git clone https://github.com/yourusername/now.git
cd now

# 2. Instale dependências
cd backend
npm install

# 3. Configure sua OpenAI API key
cp .env.example .env
nano .env  # Adicione: OPENAI_API_KEY=sk-proj-xxxxx

# 4. Inicie o servidor
npm run start:v5

# 5. Abra no navegador
# http://localhost:3000
```

## 🎮 EXEMPLOS DE USO

### Consultar Life OS
```bash
curl -X POST http://localhost:3000/api/life-os/consult \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "user123",
    "question": "Como posso melhorar minha produtividade?"
  }'
```

### Executar Trade
```bash
curl -X POST http://localhost:3000/api/ai-trader/execute-trade \
  -H "Content-Type: application/json" \
  -d '{
    "symbol": "AAPL",
    "action": "buy",
    "quantity": 10
  }'
```

### Processar Emails
```bash
curl -X POST http://localhost:3000/api/email/auto-process
```

### Adicionar Item de Compra
```bash
curl -X POST http://localhost:3000/api/shopping/add \
  -H "Content-Type: application/json" \
  -d '{
    "product": "Café",
    "quantity": 1
  }'
```

## 🌍 DEPLOY EM PRODUÇÃO

### Opção 1: Vercel (Recomendado)
```bash
# 1. Instale Vercel CLI
npm i -g vercel

# 2. Login
vercel login

# 3. Deploy
vercel --prod

# ✅ Pronto! Seu NOW está online
```

### Opção 2: Heroku
```bash
# 1. Crie app
heroku create now-ai-assistant

# 2. Configure vars
heroku config:set OPENAI_API_KEY=sk-proj-xxxxx

# 3. Deploy
git push heroku main

# ✅ Pronto! Seu NOW está online
```

### Opção 3: VPS (AWS/DigitalOcean)
```bash
# 1. SSH no servidor
ssh root@SEU_IP

# 2. Clone projeto
git clone https://github.com/yourusername/now.git

# 3. Instale dependências
cd now/backend && npm install

# 4. Configure PM2
pm2 start ecosystem.config.js
pm2 startup
pm2 save

# ✅ Pronto! Seu NOW está online 24/7
```
