⚠️ Importante

Este APK é uma versão debug (desenvolvimento). Você precisará habilitar "Instalar de fontes desconhecidas" nas configurações do Android para instalar.

📲 Como Instalar

1

Baixar o APK

Clique no botão de download acima. O arquivo será salvo no seu celular.

2

Habilitar Fontes Desconhecidas

Configurações → Segurança → Ative "Fontes desconhecidas"
(Android 9+: Configurações → Apps → Acesso especial → Instalar apps desconhecidos)

3

Instalar o APK

Abra o arquivo baixado, toque em "Instalar" e aguarde. Pode aparecer um aviso de segurança, toque em "Instalar mesmo assim".

4

Conceder Permissões

Ao abrir o app, permita o acesso ao microfone (essencial para reconhecimento de voz).

5

Testar!

Fale "Olá" ou "Que horas são?" e você deve ouvir a resposta! 🎉

🔊 Diferença: Web vs APK

  • Web (Chrome): ❌ Voz bloqueada por política do navegador
  • APK Nativo: ✅ Voz funciona 100% (usa API nativa do Android)
